Color System

A structured palette system divided into primary brand foundations, strategic accents, neutral greys, and WCAG AA contrast rules.

Neutral Interface Grey Ramp

Use these neutral values for UI backgrounds, hairline borders, body copy, and caption text:

Grey 50 — Page Background
Grey 100 — Card Surface
Grey 200 — Hairline Border
Grey 400 — Caption & Muted Text
Grey 600 — Secondary Body Text
Grey 900 — Primary Headlines

Color Contrast & Accessibility Safety

Designers must ensure text and background combinations meet WCAG AA standards (4.5:1 for body text, 3:1 for large display text):

Background Text Color Contrast Ratio WCAG AA Status Approved Usage
Deep Navy (#070732) White (#FFFFFF) 18.4:1 PASS (AAA) Body text, headlines, specs
Deep Navy (#070732) Electric Green (#A6E35F) 12.2:1 PASS (AAA) Stats, metrics, highlights
White (#FFFFFF) Deep Navy (#070732) 18.4:1 PASS (AAA) Body text & headings
White (#FFFFFF) Blue Orchid (#3343FF) 5.8:1 PASS (AA) Large headings & links
White (#FFFFFF) Electric Green (#A6E35F) 1.4:1 FAIL NEVER USE (insufficient contrast)
